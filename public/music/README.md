# Muzyka

Kaho ma własny, generowany na żywo soundtrack (Web Audio, `src/lib/sound.js`),
więc działa bez żadnych plików audio i bez problemów z prawami autorskimi.

Żeby użyć własnych utworów, wrzuć tu pliki:

```
public/music/lobby.mp3      # poczekalnia
public/music/question.mp3   # w trakcie pytania
public/music/results.mp3    # wyniki / podium
```

Pliki audio są w `.gitignore`. Nie commituj utworów, do których nie masz praw
(np. OST Balatro, S.P.L.I.T., Kryptic) — repozytorium jest publikowane.
